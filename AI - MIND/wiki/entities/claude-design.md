# Claude Design

Claude Design appears in the raw sources as a design-agent environment for creating HTML-based design artifacts, prototypes, decks, docs, PDFs, standalone HTML, and design-to-code handoffs.

## Useful Patterns

- Start design work by clarifying purpose, fidelity, constraints, brand, design system, and desired variation count.
- Treat design output as a real artifact that needs verification.
- Capture implementation handoff details: screens, states, behavior, tokens, assets, and target files.
- Use GitHub/codebase context to inform design when available.

## Caveat

The Design Component format and many tool names are specific to Claude Design. This brain should preserve the workflow ideas and not assume those exact tools exist in Codex.
