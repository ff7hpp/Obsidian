# AI Mind

![AI Mind graph view](assets/ai-mind-graph.png)

> A living Markdown knowledge base for building products, apps, websites, and better ideas with Codex.

AI Mind keeps the important parts of your work: decisions, architecture, patterns, lessons, and sources. Your projects stay independent; the brain stores their reusable essence.

## Structure

```text
AI - MIND/
├── raw/       Original sources
├── wiki/      Distilled knowledge
│   ├── projects/
│   ├── concepts/
│   ├── entities/
│   └── sources/
├── CODEX.md  Operating rules
└── wiki/index.md
```

## Commands

| Command | What it does |
| --- | --- |
| `add` | Ingest a file, link, skill, or source into the wiki. |
| `update` | Learn from current project repositories and refresh the wiki. |
| `check` | Find stale claims, contradictions, orphan pages, and gaps. |

## Principles

- Plain Markdown and portable files.
- Original sources stay untouched.
- Secrets, dependencies, caches, and generated files stay out.
- Every important claim is traceable and verified.

See [CODEX.md](AI%20-%20MIND/CODEX.md) for the complete workflow.
