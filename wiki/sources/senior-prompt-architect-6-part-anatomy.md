# Senior Prompt Architect — 6-Part Anatomy

Source file: `raw/senior-prompt-architect-6-part-anatomy.md`

## Summary

A prompt-writing workflow that converts a basic idea into a high-fidelity prompt through six fields:

- Role: expert persona.
- Task: specific objective.
- Context: environment and risks.
- Reasoning: strategic logic.
- Stop Conditions: success criteria.
- Output: exact format and fields.

## Trigger

Begin by asking: “What project or task do you want to work on today?”
