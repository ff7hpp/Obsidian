# ANKAGEO Internship Materials

Summary of the internship email, roadmap PDF, and four supplied links.

## Relevant Project Options

- SaaS GIS Cloud.
- Routing service and map-based navigation.
- Event tracking map application.
- Person/vehicle counting and license-plate recognition.
- Generic CRUD/full-stack web applications.

## Internship Evaluation Signals

The email asks for a project plan, requirements document, software/system design, GitHub code, a working application, and weekly presentations. The PDF emphasizes responsive design, reusable code, REST APIs, databases, authentication/authorization, testing, security, deployment, and SDLC.

## Preserved Decision

The recommended direction is to evolve GeoIssue into an operations-oriented GIS platform combining SaaS GIS and map-based issue/event workflows. This gives the company a directly relevant demonstrable product while keeping computer vision and fleet navigation as later integrations.
