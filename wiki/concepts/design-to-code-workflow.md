# Design To Code Workflow

Design-to-code workflow connects product intent, design artifacts, UI states, implementation notes, and verification into one handoff path.

## Useful Handoff Shape

- Overview of the feature or product.
- Design files and source links.
- Fidelity level and what is intentionally unfinished.
- Screens and views.
- Interactions and behavior.
- State management.
- Design tokens: colors, typography, spacing, radii, shadows.
- Assets and licensing constraints.
- Files and implementation targets.
- Verification notes and known caveats.

## For Apps And Websites

When building a website or app, future wiki pages should capture both product decisions and implementation mapping. A design is not just visual reference; it should become build context for Codex.
